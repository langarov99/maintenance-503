================================================================
  ПАПКА ЗА ОБНОВЛЕНИЯ — Data Extraction Bot
================================================================

КАК СЕ ПРИЛАГА ОБНОВЛЕНИЕ:

  1. Уверете се, че ботът НЕ работи
     (затворете START.bat ако е пуснат)

  2. Поставете update.patch в ТАЗИ папка (updates\)

  3. Щракнете двукратно върху APPLY_UPDATE.bat

  4. Изчакайте "[OK] Обновлението е приложено успешно!"

  5. Стартирайте бота с START.bat


ВАЖНО:
  - Прилагайте обновленията по ред, не прескачайте!
  - Файловете с данни (*.xlsx) се копират ръчно при нужда
    в папката: data\suppliers\
