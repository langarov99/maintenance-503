# Data Extraction Bot

Локален бот за извличане на продуктови данни от PDF, Excel, текстови файлове и снимки.

## Структура на изходния Excel

| Колона | Поле |
|--------|------|
| 1 | Код на продукта |
| 2 | Количество |
| 3 | Доставна цена (с/без ДДС) |
| 4 | Име на продукта |
| 5 | EAN / Баркод |
| 6 | Килограми (бруто/нето) |
| 7 | Брой/части в комплект |
| 8 | Цвят (опционално) |

## Поддържани езици
Bulgarian (bg), English (en), Polish (pl), Czech (cs), Italian (it), German (de)

## Инсталация (само веднъж)

1. Копирайте цялата папка на USB флашка
2. (Опционално) Поставете WinPython в `WinPython/python-3.11/`
3. Стартирайте `INSTALL_FIRST_TIME.bat`
4. (Опционално) За AI режим: свалете `phi-3-mini-4k-instruct-q4.gguf`, преименувайте на `phi-3-mini.gguf` и поставете в `models/`

## Използване

1. Стартирайте `START.bat`
2. Браузърът се отваря на `http://localhost:5000`
3. Пуснете файл (drag & drop)
4. Изберете езика
5. Натиснете "Извличане"
6. Свалете готовия Excel

## Автоматичен превключвател

```
Файл → Четене → Опит 1: Таблица (структура)
                    ↓ неуспешно
              Опит 2: Regex (умни правила)
                    ↓ под прага на увереност
              Опит 3: AI/LLM (phi-3-mini, само ако е инсталиран)
                    ↓
              Excel изход с 8 колони
```

## LLM модел (опционален)

Свалете от: https://huggingface.co/microsoft/Phi-3-mini-4k-instruct-gguf
Файл: `Phi-3-mini-4k-instruct-q4.gguf` (~2.3 GB)
Поставете в: `models/phi-3-mini.gguf`
